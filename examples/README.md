# Учебные примеры

В каталогах находятся редактируемые DOCX-примеры для документов по синтезу NMC и сборке/испытаниям литий-ионных аккумуляторов.

Все значения являются демонстрационными и не должны использоваться как технологические инструкции, спецификации или критерии приёмки. Перед практическим применением замените их утверждёнными данными организации.

Файлы можно напрямую редактировать в Word или LibreOffice. Перед изменением рекомендуется сохранить резервную копию.
